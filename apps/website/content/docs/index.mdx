Party Stack brings reactive queries, optimistic actions, offline data, files,
authentication, and authorization into one TypeScript framework. Connect an
existing system or host your own backend.

Each replica stores the parent data it needs, pending actions, and their predicted
changes. Query demand determines what it loads from its parent.

## Build the UI

- [Queries](/docs/queries): render reactive collections.
- [Actions](/docs/actions): submit changes and handle failures.
- [Attachments](/docs/attachments): attach files, display images, and read metadata.
- [Encrypted values](/docs/encrypted-values): decrypt properties and choose whether to cache them.
- [Offline data](/docs/offline): keep a project available and choose cache limits.
- [Authorization](/docs/authorization): scope rows, properties, and actions to a caller.
